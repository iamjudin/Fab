# Fab 0.1.0-beta.38

This beta restores explanations behind the maintained knowledge and improves
how collaborative discussion uses them.

- Preserve definitions, relationships, alternatives and useful examples across
  the 15 registered research packets. The two repair stages enrich 37 existing
  meanings without adding another knowledge store or rewriting the originals.
- Explain supported technical foundations before asking about an actual local
  choice. Reassess inherited handoff questions instead of repeating their premise.
- Require website content-payload review before final build, handoff or publication,
  with purpose-specific exceptions for large originals and downloads.

Validation: complete retained-source review, deterministic build/package checks
and one fresh read-only audio-note discussion with correct connected explanation
and a meaningful next question. The latter is one prompted source-snapshot case,
not sustained collaboration, a causal comparison, native behavior or human
usability evidence. Website optimization is an instruction-level correction,
not a newly executed website benchmark. Existing Canvas and platform limits remain.

No automatic monitoring, other-project rewriting or cross-chat adoption is added.
After updating, an existing chat needs to reread the installed relevant instructions.
Rollback uses v0.1.0-beta.37.
