# Fab 0.1.0-beta.22 — first public beta

This release makes the existing independent Fab skills available through the
GitHub repository marketplace. It adds MIT licensing, attribution notices,
repository metadata, and installation/update/rollback instructions. Runtime
behavior instructions are unchanged from beta.21; this is a distribution increment.

## Package and scope

- Ten independent skills and optional partial routes for indie creators.
- Mobile app focus; shared product meaning with conditional platform guidance.
- Structure/scenario tables by default; block screens and executable prototypes
  remain independent outcomes.
- Repository marketplace selector: `fab@fab-local`.
- Versioned source tag: `v0.1.0-beta.22`. Previous checkpoints remain unchanged.

## Evidence and limitations

Package integrity, local regressions and the declared beta-scope gate are checked
before publication; actual remote CI and clean public installation are recorded
separately in the [distribution report](../../experiments/releases/public-beta22-20261012/report.md).
Historical fresh-model/browser evidence remains bounded historical evidence;
there is no new full-route or all-skills model validation for this release.

Canvas label overlap remains a known defect (WF-20). Canvas is experimental
opt-in; native Obsidian has no readiness claim. Sustained context continuity,
queued Canvas-chat recovery, fresh generated-plugin cleanup and several research
annotation cases remain open. No native/device/offline/billing/production guarantee.
Research packets retain partially verified citation coverage.

## Install, update and rollback

```sh
codex plugin marketplace add iamjudin/Fab --ref v0.1.0-beta.22
codex plugin add fab@fab-local
```

For an update or rollback, select the desired published version tag and reinstall
the same selector. The host must support Git-backed plugin marketplaces. This
release is a GitHub prerelease; it is not a public-directory submission.

Original Fab material is MIT licensed; [attribution notices](../../NOTICE.md)
preserve external-source rights and research limitations.
