- The refreshed *For the Win* digest adds examples of suitability, the meaning
  of rewards, element purpose, progression and incentive effects.

  spacing between component instances, and how to distinguish search scope

source qualifications. Actual Figma and native rendering require separate
evidence. This update was checked through the deterministic knowledge build,
reader queries, package validation and the existing regression suite.
