# Fab 0.1.0-beta.41

Fab's shared collaboration guidance now explicitly treats the creator's time
and attention as resources. Lead with the decision or recommendation, group
related points, and retain the reasons, tradeoffs and conditions that could
change the decision when shortening a response. Simple confirmations can
remain one sentence.

This beta promotes the guidance previously installed as a local candidate.
Package and regression checks verify the distribution. How the new guidance
affects a substantive proposal in an existing chat remains to be observed.

Rollback: v0.1.0-beta.40.
