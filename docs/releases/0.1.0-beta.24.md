# Fab 0.1.0-beta.24 — useful dialogue and growing-task handoff

Brainstorm now develops an open question through meaningful alternatives,
grounded distinctions, reasoned critique and focused questions. It applies nearby
project evidence when a seemingly small change affects meaning, effort or choice,
incorporates feedback and preserves accepted constraints. Sound ideas can receive
reasoned agreement. Cosmetic tasks stay brief; Six Thinking Hats perspectives
are optional tools rather than a mandatory answer format.

Fab also reassesses task growth during work and proposes a separate chat when a
substantial independent workstream would benefit from its own dialogue. After
explicit agreement to that proposal, it transfers a durable context packet and
checks actual recovery using available host tools. Branch isolation alone is not
a completed handoff; automatic chat creation is not promised.

## Evidence and limits

The original sixteen-turn comparison was inconclusive. Six contextual turns
preserve the initial depth miss and a narrow v2 correction. Five varied virtual
situations/seven v2 turns support useful contributions, critique/agreement,
feedback, exploration and constraint preservation on GPT-6.1 Sol/Medium. One
copy example assumed an unspecified timing anchor; that limitation is retained.
These are bounded, unblinded checks, not statistical superiority or long-context
stability. Source integration preserves the tested Brainstorm files exactly.

Package/regression/scope and exact-tag distribution checks are recorded in the
[release report](../../experiments/releases/dialogue-beta24-20261013/report.md).
New shared chat-separation behavior and host recovery need their own evidence;
Canvas remains experimental with a known readability failure. Existing native,
production and real-user limits remain open.
