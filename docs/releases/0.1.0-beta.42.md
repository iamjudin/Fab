# Fab 0.1.0-beta.42

Fab keeps the identity and known revision of sources that inform decisions and
artifacts. This beta removes the former project-tag and source-note metadata
workflow from Fab, including its bundled write helper. Existing notes and
tags stay in place. Fab remains standalone.

The rest of the package is based on beta.41. Canvas remains experimental.
Use the [installation instructions](../install.md) to update or return to
beta.41.
