# Fab 0.1.0-beta.23 — brainstorm, build, ship

Fab now uses the creator's factory icon and the approved short description
**brainstorm, build, ship**. The name stays **Fab**; the full description explains
**Fabricator** and the independent tasks it supports.

- Practical use cases lead the README, followed by the optional thinking,
  building and shipping groups. Installation and developer details are shorter
  and linked below.
- Git/GitHub artifacts use English independently of conversation language.
  Source research and historical evidence retain their recorded language.
- Public-release guidance resolves approved branding before publication.
  Package validation checks both image references and listing metadata.
- The supplied 512×512 PNG is bundled unchanged as logo and composer icon.

See [installation/update/rollback](../install.md), [beta limits](../limitations.md)
and the [verification report](https://github.com/iamjudin/Fab/blob/codex/fab-maintenance/experiments/releases/branding-beta23-20261012/report.md).
Canvas remains experimental; package/branding checks do not prove native host
rendering or universal skill behavior. Beta.22 and its assets remain historical.
