# Fab 0.1.0-beta.30 — value, motivation and practical design knowledge

This beta adds three qualified knowledge modules and applies a retained
onboarding lesson to the first-value method. Existing project decisions remain
the starting point. None of these methods creates a compulsory pipeline.

- **Onboarding:** distinguish the person's desired value, the concrete first
  experience and necessary setup. Justify fields and commitments by their actual
  consequence. Explain value without promising an unproved product effect.
  Product and Analysis have explicit conditional routes. No fixed slide count
  or account/payment order.
- **Motivation and gamification:** use Werbach and Hunter's *For the Win* to
  examine suitability, participant motives, feedback, progression and incentive
  conflicts before choosing rewards. The packet contains an original attributed
  synthesis, not the full book or private illustrated digest.
- **Layout and typography:** connect grouping, hierarchy, Russian interface text
  and content adaptation to the active layout question. Source numbers are
  qualified, and the brief separates W3C user text-spacing support from authored
  defaults. Missing practitioner coverage and native evidence remain explicit.
- **Repository presentation and distribution:** connect README first use,
  visitor roles and proportionate delivery setup. Independent intake checks
  qualify tag/archive stability, immutable-release protection and archived Actions.
  Existing release authority and actual channel checks still apply.

Twelve brief/packet pairs retain 572 indexed sections. All twelve packets remain
unchanged by release preparation. Earlier supplied sources retain their claims
and limits. The new book packet preserves its selective authored synthesis only.
Source tagging remains additive, with project-level consent and no renaming.

## Verification and limits

77 local regressions, packet/registry/reference checks and the scoped beta gate
cover technical integrity. No new model test, native rendering, participant study,
conversion gain or durable behavior-change evidence is claimed. Historical
examples, legal/platform assertions and population-specific effects require
appropriate evidence for the actual decision. Research intake is not full
empirical validation. Canvas stays experimental, and Bookworm is unchanged.

Local installation and public assets are verified separately in the
[distribution receipt](../../experiments/releases/knowledge-beta30-20261016/report.md).
An existing chat must reread the updated relevant instructions after installation.
Installation does not establish automatic adoption by another chat.

Rollback: beta.29. Earlier tags remain immutable.
