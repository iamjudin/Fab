# Fab 0.1.0-beta.29 — project tags without renaming

Library material now records project use with nested tags, keeping the source
name and all existing tags. This applies to research, book notes, articles and
other reusable material, including use through Analysis or another direct skill.

- Add `project/fab`, `project/ujitsu`, `project/once` or the accepted project slug.
  Existing Bookworm, custom, legacy and other-project tags remain.
- Keep filenames and headings unchanged. Do not add project prefixes or silently
  undo existing names. A rename remains a separate explicit task.
- Remove explicitly managed visible usage sections from the reader introduction.
  Useful technical history goes into an optional hidden EOF comment. Processing
  metadata also stays in the consuming project's provenance.
- Cosmetic tag changes do not refresh studies, processing dates, another consumer's
  revision or accepted product decisions. Existing source-write permission applies;
  otherwise offer the exact tag once, without blocking the useful result.
- A package-contained helper previews exact changes, requires the reviewed source
  hash before applying, preserves body bytes and refuses ambiguous YAML or aliases.
  No Bookworm dependency or automatic whole-vault migration.

## Verification and limits

77 regressions and package/scope checks cover the payload. Two fresh GPT-6.1
Sol/Medium cases check a book-note Analysis and an already processed research
source, including actual writes, tag/body/name preservation and useful partial
outcomes. Root checks actions and idempotence. Source behavior passes; aggregate
input exceeds the planned test budget due to parallel-run forecast error. The
original process failure is retained, with no further model launch.

Ten explicitly approved existing managed source blocks were migrated with exact
body/name/prior-tag/history preservation. Private library files and backups are
not part of this public package. Native Obsidian rendering, arbitrary YAML, every
cross-project case and long-context stability remain unproved. Canvas/Bookworm
are not changed. Older version tags remain immutable; rollback beta.28.
