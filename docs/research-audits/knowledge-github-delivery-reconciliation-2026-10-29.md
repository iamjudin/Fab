## Maintainer contrasts and limits

A library consumer and app user need different first-use detail. Source build
is not product installation. CLI screenshots can be useful. A personal project
need not add a site/forum/changelog solely for apparent maturity. A tag label,
source ZIP, release asset and installed version are not interchangeable.
Protection enabled is different from a Release merely existing. CI success
does not establish first use. Public visibility does not settle all rights.

These are maintainer review contrasts. No actual channel installation, replacement
action test, licensing conclusion, case reproduction or human comprehension study
is performed. [Result](../../experiments/maintenance/knowledge-github-delivery-20261029/report.md).
