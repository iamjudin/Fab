# Маяк Fab
Канонические принципы: [runtime core](../plugins/fab/shared/core.md).
Пять групп: полезный результат и соразмерность; сохранность замысла;
соавторство и внимание; честная проверка; движение и обучение.
Каждый прямой навык читает core. Методы/детали только по вопросу.
Продуктовые этапы позже составят отдельный маршрут, не обязательную лестницу
для анализа/исследования/brainstorm. Тесты не доказывают реальную ценность.
После устойчивого нового принципа проверяем core→skill→check→evidence.
