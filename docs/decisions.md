# Решения
- 2026-10-10: отдельный Fab repo; один bundle с независимыми outcomes.
- Shared core — canonical; краткий человеческий Маяк ссылается на него.
- Beta: cowork/research/analysis, затем brainstorm/testing; остальные owners
  не активируются пустыми placeholders.
- Brain human originals остаются внешними, packaged methods самодостаточны.
- Old plugin installs сохраняются; тесты новой identity фиксируют actual runtime.
- Выпуск позже через delivery с domain adapters; обычный push не публикация.

- 2026-10-10: private iamjudin/Fab remote created and identity/privacy verified;
  codex/bootstrap-beta and beta1recovery tag pushed, no main merge/public release.
- Whole-model creator-side assessment required, separate from mandatory BJ count;
  partial feature/UC requests do not need an artificial full Jobs hierarchy.
- Checkpoint is persistence, not a stop. Continue until agreed outcome or actual
  decision/access/budget boundary. Live preview lifetime distinct from data lifetime.

- Physical ownership is required only for structure Canvas; flow-only maps
  excluded, separate global navigation allowed. Geometry guard is not semantics.
- Recovery testing must use accessible controls in the actual failed state;
  changing inert background controls in a harness is insufficient evidence.
