# Contextual knowledge authoring and build

The maintained current view covers the fifteen registered source packets.
Supporting project research outside that registry is not automatically included.
Preserved originals remain evidence. The repository source of curated meanings
is [current.json](current.json); the packaged runtime reads
only its compiled current view and self-contained reader.

Edit an existing meaning before creating another overlapping recommendation.
Keep stable IDs, concrete read aliases, applicability/exceptions, evidence limits
and meaningful condition/contradiction links. The body is preserved verbatim by
the compiler; compilation is not summarization or semantic verification. A
versioned technology example keeps its target version; a local observation never
becomes a shared rule merely through successful execution.

Each authoring source binding records the original repository archive location,
section ID and exact text digest. `python3 -B scripts/build_knowledge.py` validates
these, rejects invalid relationships/authority and emits current meanings plus
source receipts. `--check` rejects stale output without writing. Identical inputs
produce identical bytes. Failed source validation does not replace the last good
view. The package CLI includes that check; originals need not be installed for
ordinary runtime reads.

Runtime integrity checks use compiled content digests and receipts, not archive
I/O. Receipts describe provenance and build-time matching; they are not a trusted
clock, cryptographic publisher signature or independent fact check. Full source
packets still exist for other current method consumers and on-demand history.
Do not delete them before their owners/references are migrated deliberately.

Seventy-five qualified active meanings are compiled. The obsolete dimension example is
a body-free tombstone, so its text cannot leak through ordinary reads. Synthetic
local naming test data remains in historical experiments, outside shared knowledge.
Explicitly accepted project evidence can be supplied through an optional
schemaVersion2 state, with family, per-unit retirement pins, reasons and observations
bound to exact unit revisions. Each observation has id/aboutUnit/unitRevision/
text/origin and is returned as project-only evidence. It cannot replace a global
meaning or change authority. Unrelated source-envelope or other-unit changes do
not invalidate unchanged per-unit bindings; changed units require explicit review.

The current family is `fab-knowledge`. Legacy `fab-design-system` project states remain valid only for their original unit IDs and exact unchanged unit revisions. State is not a new mandatory project file or
authenticated authorizer. Use existing accepted project artifacts; no source text
can itself grant permission. Tests for compilation, archive independence,
retirement/local authority and stable bindings live in
[the knowledge-view regression](../tests/test_knowledge_view.py).

## Cross-topic discovery

One editable `current.json` owns each of75active meanings across all twelve source-reconciled families. The method index/briefs
route by the actual decision; the migration inventory records source coverage.
No second operational summary or separate topic store owns the same meaning.

Aliases, titles, topics and triggers support lexical `--query`. This is not
embedding retrieval or complete Russian morphology. No match does not establish
absence. Use a relevant method brief, a shorter domain term or the index when a
natural sentence misses. Query results contain discovery metadata; read the
selected ID and its qualifications before applying it.

Stable IDs persist across reviewed changes. An alias-only edit changes that
unit's exact revision too; local pins require explicit review. Unchanged units
retain their revisions. Legacy project-state family names can bind only their
original IDs, not new topics. Associations do not create prerequisite authority.

## Completion boundary

A migrated meaning has one authored body, compiled output and active reader route.
Its former brief keeps only routing/coverage and necessary provenance, without a
competing paraphrase. Unmigrated remainder stays explicit until reconciled; source
packets remain preserved evidence. Build checks establish integrity, not semantic
coverage or successful use. Source-only closure is separate from distribution.

All fifteen registered source packets (twelve coarse families,816sections) now
have recorded dispositions. Selected reusable decisions live in75current meanings;
historical examples, implementation sketches, bibliographies, superseded advice
and dated details retain explicit reasons and evidence limits in source audits.
Source reconciliation does not supply missing citations, conduct omitted research,
prove current platform facts or establish observed application. Supporting research
outside the registered packets is outside this reconciliation scope.

## Bounded reading

A selected `--unit` returns its full current body and the necessary condition
and contradiction closure. Other `related-to` associations are compact discovery
leads with IDs, not preloaded bodies. Read a relevant lead explicitly.
`--unit ID --expand-related` requests association bodies when the wider context
is needed. Query/index remain discovery metadata. This keeps relevant exceptions
available without flooding every read with neighboring topics. Retirement and
local-evidence boundaries still apply; compact output does not hide a condition.
