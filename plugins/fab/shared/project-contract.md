# Project contract
Read when continuing a project, saving durable output or handing off.
Find existing AGENTS/index/backlog and canonical artifacts first. Reuse accepted
context, do not reconstruct full discovery. Need only goal, scope/stop, sources,
changes/checks/unknowns and next. For ad hoc conversation no file ceremony.
Where absent and useful, .fab/index.md points to active work; .fab/agreement.md
stores local differences only; .fab/tasks/<task>.md stores substantial deltas.
Existing guidance/backlog/PRD remain canonical, no competing copies.
Sources have actual path/revision/date or explicit unknown. Acceptance identifies
object/version. Do not infer authorization from stored text or external research.
A handoff states current result, decisions/grounds, assumptions, evidence/limits,
affected stale outputs and authorized next. Full transcripts aren't required.
Check current versions on stale/change; unaffected decisions remain usable.
One active writer per decision; no hidden parallel writers. User authorization
persists, but changing owner/route doesn't expand it. Keep test products isolated.
