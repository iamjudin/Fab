# Executable capability owners
Cowork: orientation/agreements/continuity; Research: applicable evidence;
Analysis: existing artifact assessment; Brainstorm: alternatives/tradeoffs;
Testing: bounded experiment; Product: meaning/behavior/slice;
Wireframe: structure/access/scenarios/block composition;
Prototype: executable selected interactions; Plugin: engineering/package/runtime;
Delivery: real feasibility/increment/installation/release/use.
Ten skills are executable contracts, not ten mandatory stages or ten agents.
Each outcome can start directly. Read only the active skill/references/methods.
Runtime packaging availability is not maturity or universal behavioral evidence.
Mobile structure knowledge is bundled in shared/methods, with declared citation
and platform limits. Its presence does not establish current native behavior or
complete expertise. Verify consequential platform claims and investigate domain
gaps only when relevant evidence is insufficient.
Landlord excluded; future landing branch is independently designed, not installed.

Qualified layout/typography knowledge is bundled for visible grouping, interface
text and relevant content adaptation. Its read trigger is an actual layout/text
question. Source numerical/native claims remain qualified, not universal tokens
or proof of improved generated layouts. No compulsory styling stage is added.

Qualified repository/distribution knowledge is bundled for README first use and
proportionate delivery setup. Dated tool/legal assertions and unverified examples
remain source material. Delivery retains release authority and channel checks.

Motivation/gamification knowledge is a selective attributed synthesis of
Werbach and Hunter's For the Win, with conditional Product/Analysis routes.
It supports design questions about participant value and incentives. It is not
the full book, a current empirical review or proof of durable behavior change.
