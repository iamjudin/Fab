# Brainstorm
Use the actual question, context and findings; name which assumptions are open.
Choose divergence, critical examination or convergence according to intent.
Propose meaningfully different options, tradeoffs and a recommendation grounded
in the person's goal. Avoid premature specifications or forced scoring grids.
Separate speculative possibilities from known evidence. Market/platform facts
need evidence; route research when it would change the choice.
Can finish with alternatives and unanswered questions. Don't mark an option
accepted until creator decision or existing explicit authority supports it.
Advice/critique is shared culture, not exclusive to this skill. No automatic
product pipeline, documents or coding because an idea sounds promising.
