# Intake: meaningful frame without ceremony
Determine creator intent (personal, commercial, client, internal, learning) and
input flexibility/default authority from the actual request. Keep known explicit
exceptions/non-goals, current behavior vs obligation, evidence vs preference.
If intent/flexibility already clear, don't repeat questions or require a separate
approval message. A significant ambiguous human choice waits; independent work
continues. A request to produce candidates authorizes that work, not accepted
market truth or unlimited build. Only useful missing questions, no element-by-element
interrogation. Preserve unusual input signals and their reasons before narrowing.
For new durable model save frame/signals/state in isolated product workspace;
existing task uses current accepted context. Default status doesn't erase explicit
constraints. No unsolicited monetization or account/sync guarantees.
