# Проверка отмены редактирования

Дата: 2026-10-10. Источники: [requirements.md](requirements.md), [subject.py](subject.py).

## Гипотеза и границы

При отмене результат должен сохранять прежний объект saved, когда draft отличается от него. Отдельно проверяется отсутствие изменений входных объектов. Это синтетический модуль, не UI. Исправление исключено из эксперимента.

Среда: локальный Python 3.9.6. SHA256 subject.py: `87ebd0373c51513db1c059ce785ab7d817cc6ecea36cd160c92c9c59cda2ca11`.

## Метод и бюджет

Один вызов cancel_edit с saved = `{'value': 'saved'}` и draft = `{'value': 'draft'}` в [experiment_cancel.py](experiment_cancel.py). Проверки идентичности и содержимого различают возврат прежнего объекта и возврат черновика. Бюджет: один тестовый запуск; остановка после различающего результата.

Команда: `PYTHONDONTWRITEBYTECODE=1 python3 experiment_cancel.py`.

## Наблюдение и вывод

```text
result: {'value': 'draft'}
result is saved: False
result == saved: False
result == draft: True
saved unchanged: True
draft unchanged: True
verdict: FAIL
```

Гипотеза о сохранении прежнего объекта в результате опровергнута: функция возвращает копию черновика. Причина определена в subject.py: `return dict(draft)`. Даже при трактовке сохранения как равенства содержимого результат не соответствует saved. Сам входной saved не изменён; это более узкое свойство подтверждено на данном примере.

Фактическая стоимость: один процесс Python, один вызов функции; код завершения 0 означает успешное выполнение эксперимента, не прохождение требования. Модельные smoke, внешние действия и дополнительные агенты не использовались. Повторные запуски не проводились; бюджет исчерпан и различающий результат получен. Модуль и требования не изменены.

Ограничения: один контрпример достаточен для опровержения гипотезы; другие типы данных и UI не проверялись. Следующий шаг при отдельной авторизации — исправить возврат при отмене и проверить регрессию.
