# Текущий макет, текстовая спецификация
## Принятое поведение
Отмена редактирования оставляет исходные данные. При ошибке сохранения черновик
не теряется. Человек может продолжить без аккаунта. Это согласованные требования.
## Экран списка
Список вещей, кнопка добавить, настройки в navbar. Пустой список: кнопка добавить.
## Modal sheet добавления
Название, необязательное фото, Сохранить, Отмена.
При Отмене вызывается тот же save handler и добавляется запись.
После ошибки сохранения sheet закрывается; черновик очищается.
После успешного сохранения открывается блокирующий экран регистрации,
откуда нельзя вернуться в список без аккаунта.
Данных о длинных названиях и клавиатуре нет.
