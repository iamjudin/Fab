# Use Cases — кандидат v1

Все UC входят в SLICE-01; статус Assumption. Независимая цель и observable result на каждый UC.

## UC-01 — Подготовить поручение

Актор: Координатор. Триггер: Появилась работа. Предусловия: локальный контекст роли; для изменения задача существует. Основания: JS-01.1.

Ход: S-01 → S-03; название, инструкция, ответственный; сохранить.

Альтернативы/ошибки: Пустое название/инструкция: ошибка, ввод сохранён. Отмена/Escape: не создавать.

Результат: Поручение видно в списке и у выбранного волонтёра.

## UC-02 — Исправить поручение или назначение

Актор: Координатор. Триггер: Неверное описание или исполнитель. Предусловия: локальный контекст роли; для изменения задача существует. Основания: JS-01.2.

Ход: S-02 → S-03; изменить; сохранить.

Альтернативы/ошибки: Отмена сохраняет исходный объект. Можно снять назначение. Готовность не меняется автоматически.

Результат: Детали и оба списка показывают новое назначение.

## UC-03 — Найти и понять свою текущую работу

Актор: Волонтёр. Триггер: Пришёл помогать или вернулся позже. Предусловия: локальный контекст роли; для изменения задача существует. Основания: JS-02.1.

Ход: S-04: список моих активных; открыть S-02; прочитать инструкцию.

Альтернативы/ошибки: Нет задач: пустое состояние. Готовые отдельно; отменённые в отдельном фильтре.

Результат: Виден смысл работы и текущий статус.

## UC-04 — Сообщить о готовности

Актор: Волонтёр. Триггер: Работа выполнена. Предусловия: локальный контекст роли; для изменения задача существует. Основания: JS-02.1.

Ход: Своя активная задача S-02; отметить готовой.

Альтернативы/ошибки: Ошибка сохранения: исходное состояние, повтор. Чужая/отменённая: действие недоступно.

Результат: Готовность видна в деталях, истории и у координатора.

## UC-05 — Снять ошибочную готовность

Актор: Волонтёр. Триггер: Случайная отметка. Предусловия: локальный контекст роли; для изменения задача существует. Основания: JS-02.2.

Ход: Своя готовая задача: Вернуть в работу.

Альтернативы/ошибки: Доступно после позднего возврата, без таймера. Ошибка записи не меняет факт.

Результат: Своя задача снова в текущих; история сохраняет исправление.

## UC-06 — Исправить готовность

Актор: Координатор. Триггер: Обнаружена неверная отметка. Предусловия: локальный контекст роли; для изменения задача существует. Основания: JS-01.2.

Ход: S-02: отметить готовой или вернуть в работу.

Альтернативы/ошибки: Отменённая задача сначала восстанавливается. Ошибка сохранения оставляет исходное.

Результат: Скорректированный статус и автор изменения видны.

## UC-07 — Отменить ненужное поручение

Актор: Координатор. Триггер: Работа больше не нужна. Предусловия: локальный контекст роли; для изменения задача существует. Основания: JS-01.2.

Ход: S-02 → S-05; подтвердить отмену.

Альтернативы/ошибки: Отказ/Escape: без изменения. Данные, назначение и готовность сохраняются.

Результат: Задача исключена из текущих и знаменателя готовности, доступна в Отменённых.

## UC-08 — Восстановить отменённое поручение

Актор: Координатор. Триггер: Отменил по ошибке. Предусловия: локальный контекст роли; для изменения задача существует. Основания: JS-01.2.

Ход: Фильтр Отменённые → S-02; восстановить.

Альтернативы/ошибки: Сохраняются прежнее назначение и отметка; видна перед восстановлением. Ошибка записи: остаётся отменённой.

Результат: Поручение вновь активно с прежними данными.
