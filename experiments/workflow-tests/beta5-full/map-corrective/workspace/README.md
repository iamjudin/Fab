# Подготовка общественного мероприятия — локальный кандидат v1

Рабочий браузерный прототип по клиентскому брифу. Пройден путь Product → структура → критические сценарии → блочные экраны → executable prototype. Решения кандидата не приняты клиентом.

## Запуск

Требуется Python 3 и современный браузер с ES modules, `structuredClone`, `crypto.randomUUID`, `<dialog>` и localStorage. Зависимостей npm и сборки нет.

Из корня проекта:

```sh
./run.sh
```

Открой `http://127.0.0.1:8873/prototype/`. Если порт занят, используй `./run.sh 8875` и соответствующий URL. Сервер работает, пока команда открыта; Ctrl+C его останавливает. Эквивалент: `python3 -m http.server 8873 --bind 127.0.0.1`. Не открывай HTML через `file://`: ES modules и origin хранилища требуют HTTP.

Это инструкция запуска, а не обещание постоянно работающего preview. Проверочный HTTP-сервер был остановлен после проверки. Данные localStorage привязаны к браузеру и origin (включая порт); другой порт даёт другой набор данных. До первой успешной записи видны встроенные fixtures. Несохранённый ввод теряется при reload. Очистка хранилища/профиля стирает локальные данные; backup отсутствует.

## Как осмотреть

Верхняя компактная панель «настройки демонстрации» переключает координатора/волонтёра и выбранного волонтёра. Это simulation identity, не authentication. Там же находятся отказ записи и явный сброс fixtures.

1. Координатор: создай поручение с инструкцией и назначь Анне.
2. Переключись в волонтёра Анну: найди своё текущее поручение, открой инструкцию и отметь готовым.
3. Перейди в «Готовые», открой поручение и верни в работу. Undo работает и после позднего возврата.
4. Координатор: измени ответственного на Бориса; проверь историю, затем личные списки Анны/Бориса.
5. Отметь задачу готовой, отмени её. В «Отменённых» восстанови: назначение, инструкция и прежняя готовность сохраняются. Общий счётчик исключает отменённые.
6. Включи отказ записи, попробуй сохранить форму: ошибки не меняют данные, ввод остаётся. Отключи отказ и повтори.

## Проверки

```sh
node --check prototype/app.js
node tests/workflow.cjs
sh -n run.sh
```

Node 22.16.0 использовался для интеграционных проверок приложения с минимальным DOM-адаптером. Это не браузерный рендер и не UI smoke. Локальная HTTP-раздача index/JS/CSS/интерфейсных artifacts проверена отдельно: 200.

[Полная evidence и ручной browser checklist](product/evidence/checks.md). Настоящие клики, Enter/Escape, фокус, viewport и reload в браузере **не проверены**: UI-инструмент сообщил отсутствие браузеров и заблокированный Mac. Не утверждаем usability, native fidelity или принятие клиентом.

## Границы

Одно demo-событие, три фиксированных волонтёра, один ответственный на задачу или без назначения. Реальная синхронизация устройств/вкладок, authentication, native OS, подписки и marketplace отсутствуют. Доступ волонтёра — фильтр в одном приложении, не security boundary; все данные находятся в его localStorage.

У клиента неизвестны реальные права, необходимость проверки готовности, участие нескольких исполнителей, доступ и срок хранения истории. Для review применены обратимые политики, перечисленные в модели; эксплуатация требует отдельных решений и реализации. «Готово» означает заявленную готовность, не проверку качества.
