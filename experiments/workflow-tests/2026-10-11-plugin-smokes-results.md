## Создание: Note Compass
Собраны manifest, два самостоятельных skills `unpack`/`compare` и общие правила.
Использованы точные цитаты и источники, сохранены неопределённости, отсутствующие
владельцы/даты не придуманы. Одиночный запрос не требует сравнения или полного
продуктового графа. Команды внутри заметок описаны как данные, не разрешение.

Agent выполнил структурный validator и авторские разборы samples. Root отдельно
повторил validator и просмотрел SKILL/shared/результаты/страницу. Исходные samples
побайтово сохранены. Пример Android остался предположением, «до пятницы» —
относительным сроком, связь двух заметок одним проектом не была придумана.

**Граница:** outputs созданы автором пакета в том же контексте. Это контрольное
применение правил, не независимый smoke поведения установленного Note Compass.
Пограничные модельные сценарии перечислены, но не исполнены новым контекстом.
Сам агент эти уровни evidence явно разделил.

## Сопровождение: Local Index
Root до model-run воспроизвёл на отдельной копии исходного helper:
чужой index.md перезаписан, повторный результат меняется и включает себя.
Agent нашёл причины в glob всех `*.md` и безусловном write, сузил description,
уточнил исполнимую команду с абсолютными путями и ввёл маркировку своего выхода.
Он заметил пересечение с локальным backlog и не перезапустил discovery.

После завершения root запустил исправленный helper на новых копиях входа:

| Утверждение | До | После |
| --- | --- | --- |
| Чужой выходной файл сохранён | FAIL, exit 0 и перезапись | PASS, exit 1 и прежние bytes |
| Повторный результат стабилен | FAIL | PASS, одинаковые bytes |
| Выход исключён из собственного перечня | FAIL | PASS |
| Исходная alpha.md сохранена | PASS | PASS |

Три авторских regression tests также повторены root: PASS; проверены
невалидный UTF-8 тела заметки, пути с пробелами, другая cwd, чужой/старый выход,
symlink output и отсутствующий каталог. Исходные notes и accepted.md совпали
по SHA с baseline. README расширен, но весь исходный текст, включая dirty строку,
сохранён как префикс. Method.md также расширен guard-правилами, оригинальный
filename-only договор сохранён; **byte equality этих двух документов не заявляется**.

**Граница:** marker — соглашение об авторстве, не authentication; одновременные
писатели не защищены. Старые unmarked outputs отклоняются, а не мигрируются
молча. Эти ограничения отражены в странице/отчёте, метод не превращён в AI-сводку.
Installed Local Index/discovery не проверены; agent не заявил обратного.

`/private/tmp/fab-plugin-smokes-20261011/{create,repair}` и соседние JSONL/stderr.
В Fab сохранены запросы/ответы, content pages, hashes, observer и compact events;
сами сгенерированные package sources остаются вне Git Fab.
Root observer — роль, не независимый сторонний аудит и не creator acceptance.

## Что меняет решение
FAB-04 получает отдельное evidence нового plugin intent и maintenance intent
с подготовкой страниц. Новых full-runs или исправлений Fab ради статистики не нужно.
Следующая проверка Plugin нужна при конкретном ином риске: реальная установка,
discovery/маршрутизация, интеграция или сложный repair. Публичный выпуск остаётся
отдельным авторизуемым исходом Delivery. Непрерывность FAB-02 не закрывается этим
отчётом автоматически.
