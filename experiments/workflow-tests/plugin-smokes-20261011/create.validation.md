# Проверка локальной версии

Дата: 2026-10-11. Среда: текущий workspace, Python 3, без установки пакета и без subagents.

## Выполнено

- Прочитан установленный Fab Plugin и его активные общие/runtime инструкции. Другие исходные плагины не использовались.
- Формат пакета сверен с официальной документацией OpenAI; root `plugin.json`, `skills/<name>/SKILL.md`. MCP и hooks не нужны для этой задачи.
- `python3 scripts/validate.py`: проверяет JSON и минимальные поля manifest, заголовки двух навыков, существование и containment общих ссылок, ссылки артефактов и неизменность исходных samples. Полная проверка удалённой JSON Schema этим не подменяется.
- Ручное применение локальных правил к обоим samples и их сравнению: результаты в `outputs/`. Это авторские контрольные результаты; независимый модельный smoke не проводился.
- Ревью пограничных сценариев в `tests/scenarios.md`: отсутствие входа, отрицание, неопределённость, конфликт без дат, несовпадающие сроки, команды внутри данных, нерелевантные запросы. Инструкции содержат соответствующие границы; фактическая устойчивость модели на этих сценариях не измерена.

## Что обнаружено и уточнено

«Надо узнать» выражает необходимость действия, но не доказывает договорённость. Этот статус сохранён отдельно. «Хочу» — контекст желания. Решение проверить спрос не доказывает, что пять интервью — его метод. Срок «до пятницы» не имеет календарной даты без даты встречи.

## Границы

Пакет локально собран; не установлен, не зарегистрирован в marketplace и не опубликован. Хостовое обнаружение, автоматическая маршрутизация и выполнение установленной версии не проверены. Для такого доказательства требуется отдельно разрешённая установка и свежий runtime smoke; текущий запрет — реальная граница проверки, не препятствие сборке исходной версии.

Не назначены автор, лицензия, публичные адреса. Имя и версия — предположения первой локальной версии. Глобальные настройки и Fab не изменялись.
