# Проверка исправления Local Index

Проверено 2026-10-11 в отдельном локальном workspace. Установленный Fab Plugin использован как инструкция работы; изменялся только локальный пакет Local Index и документация проекта.

## Причины и исправление

`glob('*.md')` включал выходной файл; безусловный `write_text` затирал любой существующий результат. Helper теперь исключает разрешённый выходной путь и проверяет точную метку собственного результата перед обновлением. Исходные заметки не читаются; проверяется только первая строка выходного файла. Старые немаркированные результаты автоматически не присваиваются плагину.

Описание skill раньше охватывало любые заметки, исследования, планирование и сводки. Теперь положительная граница — создание/обновление локального перечня имён Markdown-файлов; отрицательная — сводки, исследования, планирование и извлечение задач. Текущий запрос о ремонте плагина относится к Fab Plugin; выполнение самого filename index относится к Local Index.

## Исполнимость и свидетельства

От `skills/index/SKILL.md` путь `../../scripts/index_notes.py` ведёт к существующему helper. Ссылка `references/method.md` существует, метод автономен и не зависит от `accepted.md` в пользовательском проекте. Команда использует абсолютные пути и не зависит от рабочего каталога. Manifest разбирается как JSON; это структурная проверка, не сертификация host-совместимости.

`python3 -m unittest discover -s plugins/local-index/tests -v`: 3 теста прошли. Проверены два запуска и побайтовое равенство результатов, исключение результата, сохранность исходных файлов, отсутствие чтения тела заметки с невалидным UTF-8, пути с пробелами, другой рабочий каталог, чужой и старый выход, выходная символьная ссылка, отсутствующий входной каталог.

Предположение: метка идентифицирует собственный результат по соглашению, запуск выполняется одним писателем. Конкурентная модификация не защищена блокировкой. Используется прямой, нерекурсивный перечень `*.md`, как в прежнем helper.

Фактическая автоматическая активация skill и поведение установленного Local Index не проверены: установка исключена условиями задачи. Это оставшаяся граница доказательств, не блокер локального исправления. Remote, коммиты, публикация и глобальные настройки не изменялись. Пользовательские строки README и accepted.md сохранены.
