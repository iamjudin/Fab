# Local Index
Мой черновик страницы: сохранить эту строку.

Незакоммиченная правка автора: нужен простой пример запуска.

## Local Index — перечень Markdown-заметок

Плагин создаёт локальный, отсортированный список имён `.md`-файлов в выбранном каталоге. Он не читает содержимое заметок, не делает AI-сводки и не извлекает задачи или решения.

### Пример запроса

«Используй Local Index: составь список имён Markdown-заметок из `/absolute/path/notes` и сохрани его в `/absolute/path/notes/local-index.md`. Содержимое заметок не анализируй».

Для проверки локального пакета из корня этого workspace:

```sh
python3 plugins/local-index/scripts/index_notes.py notes notes/local-index.md
```

Ту же команду можно повторить: собственный выходной файл исключается из списка. Существующий личный `notes/index.md` останется нетронутым и будет указан среди заметок.

Результат:

```markdown
<!-- local-index: filename-only v1 -->
# Notes index

- alpha.md
- index.md
```

### Ограничения

- Нужен Python 3; каталог заметок и родительский каталог результата должны существовать.
- Сканируется только выбранный каталог, без вложенных каталогов, только `*.md`.
- Обновлять можно только файл с точной меткой Local Index в первой строке. Чужие файлы и старые индексы без метки отклоняются; выбирай для них новый выходной путь.
- Выходная символьная ссылка отклоняется. Метка — соглашение об авторстве, а не криптографическая проверка.
- Запускай одного писателя за раз: защиты от одновременного редактирования нет.
- Локально проверены helper и инструкции пакета. Установка, реальная активация skill в новом сеансе и поведение установленного результата не проверялись.

Проверки: `python3 -m unittest discover -s plugins/local-index/tests -v`.
