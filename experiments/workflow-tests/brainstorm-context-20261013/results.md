# Contextual depth trigger — results

## Stage and recommendation

The task has advanced from general diagnosis to a focused, tested v2 candidate.
V1's general dialogue wording did not prevent the observed shallow pattern in a
bounded reconstruction. V2 adds a consequential-change check for apparently
incremental proposals. Its fresh corrective brought relevant evidence into the
reasoning before explicit depth feedback, while the cosmetic control remained brief.
Recommend this narrow direction for limited adoption review, not another mandatory
thinking framework. Implementation remains experimental; no merge, install or release.

## What changed in the diagnosis

All three initial variants read the supplied project briefs. Earlier observer
inference about missing consultation was wrong and is corrected here and in the
contract. The visible gap is applying relevant knowledge to the current proposal,
not access or a need to load more source material. Hidden model reasoning is not
observable. Merely mentioning a concern is different from explaining how it changes
the person's design choice.

V2 does not forbid agreement or require a question in every turn. It asks whether
an apparently small proposal changes meaning, effort, obligations or agency. If
so, consult nearest relevant existing evidence and explain the useful consequence.
A genuinely cosmetic request stays short. No private case details were hard-coded
into the skill, and no shared-core or other-capability rewrite was made.
