# Принятые основания существующего приложения
Личный мобильный инструмент ухода за домашними растениями; не сервис для продажи.
Один человек ведёт список растений. Нет аккаунта, оплаты, автоматического полива
и облачной синхронизации. Это границы текущего среза, не вечные запреты.
Главный контекст — список растений; добавить растение и открыть его карточку.
В списке сразу отмечают полив. Карточка содержит данные растения и историю поливов.
Название и напоминание можно задать при создании и изменить потом; напоминание
необязательное. Реальные OS уведомления не реализованы/не подтверждены.
Отмена создания/редактирования не меняет сохранённые данные. Ошибка сохранения
не уничтожает ввод. История позволяет исправить ошибочно отмеченный полив.
У нас нет готовой схемы интерфейса, но эти требования уже приняты для теста.
