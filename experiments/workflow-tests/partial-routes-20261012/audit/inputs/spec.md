# Принятые правила
Один пользователь, два независимых списка. Счётчик и «Осталось» относятся только к выбранному списку. Правка сохраняется только по кнопке Сохранить; Отмена и Escape оставляют прежнее имя. При ошибке записи пользователь не теряет черновик и может повторить сохранение без дубликата. Изменения между перезапусками сохраняются. Без сети/аккаунтов/синхронизации.
