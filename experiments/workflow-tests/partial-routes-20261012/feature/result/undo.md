# Отмена последней отметки «собрано»

Статус: предложение, новые правила не приняты. Основание: [принятая модель](accepted.md) и запрос на ограниченное дополнение от 12 октября 2026. Все правила ниже относятся только к Undo; существующая модель сохраняется.

## Доступность и границы

Предлагается один шаг отмены: Undo возвращает `packed` с `true` на `false` у последней вещи, для которой в текущей поездке успешно сохранился переход `false → true`. Цель определяется ID вещи и поездки, а не названием или положением строки.

- До подтверждения сохранения новой отметки она не становится целью Undo. Нажатие на уже собранную вещь не создаёт новую отметку «собрано».
- Следующая успешно сохранённая отметка «собрано» заменяет предыдущую цель. После успешного Undo более ранняя цель не восстанавливается: истории отмен и Redo нет.
- Успешное ручное снятие отметки с целевой вещи сбрасывает Undo. Снятие отметки с другой вещи не меняет цель. Неудачная запись не заменяет и не сбрасывает предыдущую цель.
- Добавление или переименование вещи не меняет цель Undo. Отмена добавления/переименования сохраняет прежнюю вещь, как уже принято; Undo не отменяет эти действия.
- Таймера нет: возможность сохраняется до замены цели, её ручного снятия, успешной отмены, смены поездки или reload/перезапуска. История Undo между запусками не сохраняется; сохранённые вещи, активная поездка и её фильтр восстанавливаются по принятой модели.

Это позволяет исправить случайную отметку, в том числе после исчезновения строки из «Осталось», без новой истории действий или экранов.

## Состояния и переходы

| Состояние | Доступность и поведение |
| --- | --- |
| Нет цели | Undo недоступен; сохранённые вещи не меняются. |
| Есть цель | Undo доступен для одной конкретной вещи текущей поездки. |
| Сохраняется изменение `packed` | Undo временно недоступен. Повторные нажатия не запускают новые записи. Новые изменения `packed` и смена поездки ждут завершения текущей записи; попытка смены поездки не выполняется автоматически позже. |
| Undo успешно сохранён | У целевой вещи `packed = false`; цель сброшена, Undo недоступен. |
| Сохранение Undo завершилось ошибкой | UI возвращает прежнее `packed = true`; цель остаётся, Undo снова доступен для повторной попытки. Ошибка явно сообщает, что отмена не сохранена. |

Во время обычной записи предыдущая цель удерживается, но недоступна. После успеха действуют правила замены или сброса выше; после ошибки возвращаются прежние состояние вещи и доступность Undo. Успех означает подтверждённое локальное сохранение, а не только изменение UI. Undo сохраняется сразу, как обычное снятие отметки.

## Фильтр «Осталось»

Фильтр не меняет и не сбрасывает цель. Переключение «Все/Осталось» не считается отменяемым действием. Undo доступен независимо от видимости целевой строки и не переключает фильтр.

После успешной отметки вещь исчезает из «Осталось», но остаётся целью Undo. После успешной отмены она снова соответствует фильтру и появляется в списке. Если UI показывает снятие отметки до завершения записи, появление строки предварительное: при ошибке вещь снова собрана и скрыта из «Осталось». В режиме «Все» строка остаётся видимой, меняется только её отметка. После ошибки Undo фильтр сохраняется, повторная попытка доступна даже при скрытой строке.

## Смена поездки

Завершённая смена активной поездки сбрасывает цель Undo. В новой поездке Undo недоступен до её первой успешно сохранённой отметки; возвращение в прежнюю поездку не восстанавливает старую цель. Действие никогда не изменяет вещь другой поездки. Пока сохраняется отметка или Undo, смена поездки временно недоступна согласно таблице; после результата пользователь может сменить поездку повторным действием.

## Граница ошибки сохранения

Ошибка записи Undo не считается успешной отменой и не расходует возможность повторить её. Ошибка новой отметки не делает эту вещь целью Undo; если до попытки была другая цель, она сохраняется. Ошибка ручного снятия целевой отметки также сохраняет цель.

Предложение опирается на принятое правило возврата UI к прежнему состоянию при ошибке. Если результат записи ещё не установлен, действие остаётся в состоянии сохранения: нельзя объявлять успех или ошибку и разрешать повторную запись до выяснения результата. Гарантию согласованности сохранённого состояния и UI нужно проверить при реализации; этот документ описывает поведение, а не подтверждает работу хранилища.
