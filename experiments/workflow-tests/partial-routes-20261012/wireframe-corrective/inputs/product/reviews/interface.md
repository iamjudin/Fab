# Интерфейсный кандидат

S-01 — корень navigation stack «Поездки»: заголовок, список поездок; каждая строка владеет названием, счётчиком и открытием S-02. Кнопка «Новая поездка» принадлежит экрану, открывает S-03.
S-02 — выбранная поездка: Назад→S-01, полное название, «собрано X из Y», переключатель Все/Осталось, список вещей. Каждая вещь владеет отметкой и кнопкой правки. «Добавить вещь» принадлежит поездке→S-03. Внутри фильтра нет смешивания поездок. Без tab bar: независимых верхних разделов нет.
S-03 — временная modal form с явным родителем: заголовок, label/поле, ошибка, Отмена, Создать/Сохранить. Возврат к родителю после успешной записи; отмена откатывает только черновик. Клик вне формы не закрывает её. Escape равен отмене. Это browser dialog, native sheet не доказан.

Основной сценарий: пустой S-01→создать поездку→S-02→добавить вещь→отметить→Осталось→вернуть через feedback/Все→Назад→вторая поездка→вернуться в первую→reload, прогресс сохранён.
Правка: S-02→S-03 с исходным названием→изменить→Отмена→исходное сохранено; повторить→Сохранить→новое имя.
Ошибки: пустое имя→inline error/focus; ошибка записи→форма остаётся с вводом→повторить→одна запись; ошибка отметки→предыдущая отметка и сообщение; ошибка чтения→блокирующее сообщение без стирания данных.

Блоки показаны в blocks.html до реализации. Приоритет — остаток и добавление, затем правка. Длинный текст переносится, действия не выталкиваются; пустая поездка и «Всё собрано» различаются. CSS размеры не объявляются эквивалентом iOS pt. Accessibility/native review отложены до device check.
