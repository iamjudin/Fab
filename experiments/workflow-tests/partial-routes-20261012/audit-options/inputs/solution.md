# Текущий кандидат
Два человека вручную объединяют версии списка покупок раз в день. В конфликте показываем карточку «Последняя запись победит», поле автора и два списка названий без количеств; кнопки «Применить всё» и «Пока оставить». «Применить всё» закрывает диалог и заменяет локальный список последней версией; предыдущая версия не хранится. «Пока оставить» скрывает карточку до следующего открытия.
Принято: общий список двух людей; ручное подтверждение изменений; без автоматического merge.
Наблюдения автора: 3 из 4 попыток закончились «Применить всё»; в двух после этого пропало количество у другой записи, люди заметили это только в магазине. Одну попытку отменили, потому что не поняли, что именно заменится. Это маленькая проверка процесса, не статистика рынка.
