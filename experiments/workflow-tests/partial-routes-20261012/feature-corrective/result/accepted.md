# Принятая модель
Личный iOS-first кандидат для сборов в поездку, один пользователь. Поездка владеет вещами; вещь имеет ID, название и boolean packed. Переключатель Все/Осталось относится к текущей поездке. Каждая отметка/снятие сохраняется сразу. При ошибке запись не считается успешной и UI возвращает прежнее состояние. Поездки независимы, после reload восстановлены активная поездка и её фильтр. Вещи можно добавлять/переименовывать, Отмена не меняет сохранённую вещь. Без аккаунтов/сети/синхронизации/публичного выпуска. Правила Undo ещё не приняты.
