# Кандидат продукта • 2026-10-12
Источник: запрос пользователя в этом чате. Метод: установленный Fab 0.1.0-beta.14, cowork/product/wireframe/prototype. Реального creator approval кандидата нет.

HJ-01: от нескольких разрозненных проверок и сомнений к пониманию оставшегося и завершению сборов. Основание — личный рассказ; формулировка перехода — кандидат. JS-01.1: перед поездкой понимать остаток; JS-01.2: после перерыва продолжить с достигнутого места. Альтернатива — бумажный список или заметки; снижение тревоги пока не проверено.

Creator Intent: личная польза. Отдельная creator-side трансформация не поддержана запросом: BJ/BS не выдуманы; проверка прототипа — текущий deliverable, не доказанная зрелость/поддерживаемость личного инструмента.

UC-01 создать/выбрать поездку; UC-02 добавить вещь; UC-03 переименовать; UC-04 отметить/вернуть; UC-05 показать остаток; UC-06 продолжить позже. CAP-01 поездки, CAP-02 вещи/правки, CAP-03 отметки, CAP-04 фильтр, CAP-05 сохранность — отдельные core capabilities. SL-01 включает все шесть UC.

DR-01: Trip(id,name,items[]), Item(id,name,packed). ID сохраняется при правке. Вещи разных поездок независимы. DR-02: trim, пустое/пробельное недопустимо, дубликаты разрешены; ограничение длины не вводим. Черновик отделён; Отмена/Escape ничего не записывают. DR-03: write-before-confirm; ошибка записи оставляет прежнее состояние и черновик, позволяет повторить. Ошибка чтения не перезаписывает повреждённые данные.

Candidate assumptions: порядок добавления, фильтр «Все» при открытии поездки, last-trip/фильтр сохраняются при browser reload; поездки не переименовываются/не удаляются в срезе. Категории, шаблоны, массовые действия — out, не потерянные требования. Аккаунт/сеть/оплата/push/команда исключены пользователем.

Сохранность прототипа — localStorage одного browser origin; не backup, перенос или native lifecycle. При недоступном storage нет ложного «сохранено». Native storage — следующий технический выбор, не блокер браузерного кандидата.

Обратная трассировка: SIG-01→UC-01/DR-01; SIG-02→UC-02; SIG-03→UC-03/DR-02; SIG-04→UC-04; SIG-05→UC-05; SIG-06→UC-06; SIG-07→S-02/S-03; SIG-08→SL-01. Статус всех решений — candidate, не приняты creator.
