## Useful behavior

- Analysis uses a supplied book note to recommend smaller observable changes,
  saves a concise review/local provenance and adds project/fab. Existing Bookworm,
  custom/Once tags, filename and body remain. Old managed usage history moves
  into a hidden EOF comment. No new research pipeline or other project update.
- Research adds project/ujitsu to an already processed source, preserving project/fab,
  Bookworm/custom tags, filename and body. No invented processing date/revision,
  unnecessary footer or new research. Both cases actually execute the helper.
- Root checks bytes, idempotence, tags, private before/after snapshots and action
  logs. [Assessment](assessment.json), [target](target.json) and frozen contract
  retain evidence. A helper exit code/model final message alone is insufficient.

The canonical shared contract routes every actual library use, not only research.
Sources are tagged without renaming. Existing source-write authorization applies;
otherwise the exact tag is offered once. The helper is package-contained and has
no Bookworm/Brain dependency. Type tags and project tags have different meanings.

## Deterministic coverage and limits

Eleven new tests cover additive tags/common YAML forms, other consumers, quotes/
comments/case, repeated application, visible/JSON legacy migration, record refresh,
fenced examples, BOM/CRLF/EOF and refusal of ambiguous metadata, wrong hash or file
aliases. Existing66regressions also pass. Real reader body stays byte-identical;
only source tags and explicitly managed usage metadata change. No filename change.

This is not a general YAML parser. Unsupported JSON-root/merged/multiline YAML
requires manual review. The helper migrates only explicitly bounded unfenced
metadata, not prose with a similar heading. Native Obsidian UI/render is unobserved.
[Official tags](https://help.obsidian.md/tags) and [properties](https://help.obsidian.md/properties)
document nested slash tags and the YAML tag-list representation; source inspection
and structural checks do not establish actual host display.
