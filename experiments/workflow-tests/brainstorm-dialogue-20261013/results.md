# Brainstorm dialogue comparison — bounded results

## Verdict

Candidate v1 demonstrates useful dialogue without a Six Hats mask, but these
probes do not establish an improvement over beta.23. Baseline already generated
causal alternatives, grounded criticism and useful questions. Keep v1 experimental;
do not install or release a replacement on a claimed quality win.

The creator's target is material progress in understanding, not a framework or
surface liveliness. A useful contribution can change the explanation, viable
mechanism or deciding condition. Agreement, critique, questions and brevity are
chosen according to that purpose, not added to every answer as quotas.

## What this means for Fab

The reported dissatisfaction remains valid input, but its failure mode was not
reproduced in these fresh, expressly skill-directed probes. This weakens the claim
that a missing named technique is the root cause. It does not prove everyday
collaboration is already satisfactory. Long-lived context and implicit invocation
remain unobserved; those are possible conditions to examine, not established causes.

Candidate v1 makes the expected moves more operational: contribution before a
question when possible, reasoned causal criticism, updating with feedback and
respecting a chosen direction. However, much of this overlaps existing shared
core behavior. More instruction text is not demonstrated added value here.

Recommendation: retain the experimental candidate and use the concrete criteria
for real-use observation. A future matched test should start from an actual
observed passive or superficial turn, preserve its context and distinguish what
is missing before changing the right owner (shared cooperation or Brainstorm).
Do not infer a global-core rewrite from a Brainstorm-only comparison. Do not keep
repeating easy fresh prompts until a flattering result appears.

A practical balance is: make one consequential move in an open discussion, explain
its grounds, ask when the answer changes the direction, and stop when the requested
outcome is sufficient. This is an outcome test, not a fixed turn template. Six Hats
remains an optional perspective tool; no six permanent personas or menu is needed.

## Verification and stopping

Package check and eight existing package-guard regressions passed; skill references
resolve. All model probes completed without timeout/errors and retained workspace
bytes. There was no correction rerun or substituted initial failure. The pilot
already showed a strong baseline; two reserved turns were transparently used for
Cowork entry instead of unneeded corrective runs. Stop after the declared 16-turn
ceiling and sufficient bounded evidence. Behavioral superiority, habitual dialogue
quality and real creator usefulness remain open under FAB-14/FAB-11/FAB-12.
