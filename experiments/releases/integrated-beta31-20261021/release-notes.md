# Fab 0.1.0-beta.31 — landing pages and experimental screen flows

This beta brings the integrated landing profile, screen-flow method and previously
unpublished collaboration fixes into one versioned package. Independent skills
remain independently usable. No compulsory product pipeline or new skill.

- **Landing pages:** six existing skills conditionally use the marketing-page
  profile. New pages without a chosen stack start with semantic HTML, ordinary
  CSS and only necessary JavaScript. Existing or explicitly chosen stacks take
  precedence. Preserve approved copy and distinguish real service dependencies
  from local previews. No historical Landlord workflow or runtime dependency.
- **Experimental screen flows:** explicit Canvas requests can use optional
  scenarios, genuinely reused modules and navigation overviews. Preserve caller
  origin, independent child/parent commits and actual recovery paths. The bundled
  reversible presentation helper, six color assets and improved Markdown/wiki
  fallback support review; tables remain the default representation.
- **Collaboration:** completing recovery, a relay or a correction does not finish
  an active assignment. Continue authorized useful work or surface a real choice.
  Indie is creator context, not a product-size ceiling; distinguish the initial
  delivery scope, extensible foundation and demonstrated scale.
- **Existing knowledge:** all twelve brief/packet pairs and 572 indexed sections
  remain available, with their original qualifications. Source tags stay additive
  and require one project-scoped consent decision.

## Evidence and limits

91 regressions, package/reference integrity and the exact-package beta scope gate
pass. Earlier source tests include varied input routing and one completed actual
file/check/correction workflow producing five linked maps. The workflow initially
caught and fixed missing extensions and unsafe cleanup metadata; final root review
observed real reuse, caller-specific returns, independent commits and Save retries.
That source case is bounded evidence, not installed/native behavior validation.

Earlier search recovery-binding and timer overflow misses remain recorded, as do
a timed-out workshop turn with unknown usage and an unrun scoped-edit case. Later
success does not retroactively close those failures. Canvas stays opt-in
experimental; native Obsidian rendering, sustained dialogue consistency and large-
product execution are unverified. The landing profile has source and installation
checks, not a real-project visual/conversion claim. No new model test is launched
for this release. Publication is a beta checkpoint, not universal readiness.

Local update and public distribution are verified separately in the
[release receipt](https://github.com/iamjudin/Fab/blob/codex/fab-maintenance/experiments/releases/integrated-beta31-20261021/report.md).
Existing chats should check the installed version and reread the relevant current
skills/references while retaining accepted decisions. Installation alone does not
prove automatic adoption by another chat.

Rollback: public beta.30. The prior local landing snapshot is separately retained
for offline rollback. Previous public tags remain unchanged.
