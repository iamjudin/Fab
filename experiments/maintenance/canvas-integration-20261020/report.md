## Integrated outcome

- Wireframe conditionally routes explicit screen-flow work to a bundled reference.
  Markdown tables remain the default, with block screens and physical composition
  retaining their own contracts. No new skill or mandatory pipeline.
- SC can stand alone. MOD requires actual functional reuse by distinct callers,
  with input/output and origin-specific return context. NAV is optional when it
  clarifies architecture. Screen count, complexity and repeated document links
  alone establish none of those requirements.
- Active scenario/navigation/Canvas references separate physical containment
  from behavioral-relation projection. The structure guard is not weakened or
  applied to a flow by manufacturing groups. The old control palette is confined
  to its composition view; screen-flow types own their distinct palette.
- The method preserves short actions, meaningful title/ID hierarchy, actual lists,
  framed condition/result meanings, safe gaps, owners, source IDs, commit/cancel,
  error/empty/unknown-outcome and retained return context. Six generic local color
  assets are bundled. Their native theme correspondence still needs inspection.
- A small standard-library helper accepts explicit node/edge types and bounded
  frame positions. It never infers product meaning, reuse or a whole layout.
  It checks an expected input hash, refuses existing outputs and retains reversible
  relation provenance. It does not move unrelated nodes to make a frame fit.
  Document-specific builders, phrase heuristics and messenger data stay outside
  runtime.
