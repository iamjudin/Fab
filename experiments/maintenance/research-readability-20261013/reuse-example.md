# Independent research and application example

Synthetic assignment design, not conducted research. No private source copied.

## Project-bound assignment

Which logging mode should Project Cedar launch for first-time journal users?
The team has accepted partial saving. Compare guided and free-entry logging and
recommend a launch mode.

## Independent research assignment

What evidence distinguishes the effects of guided prompts and free entry on ease
of starting, expressive freedom and repeat use in personal journaling tools?

Study first-time and experienced journal users separately. Compare required and
optional prompts and the ability to save incomplete entries. Preserve observation
period, participant experience, task context, counterevidence and transfer limits.
Do not infer repeat use from completion of a single session. Distinguish source
findings from design hypotheses. Follow the research reader contract for comparison,
causal explanation and supporting detail. Do not recommend a launch configuration
for a consuming project in this independent report.

The accepted project rule has become a topic condition to investigate, not a
universal requirement. The project name and launch decision are not research
findings. Retaining user experience and task context keeps the question useful.

## Review cases

| Case | Expected boundary |
|---|---|
| New topic research used by one project | No consuming-project name or local decision in research, relevant conditions retained |
| Same topic reused by another project | Recheck evidence revision, freshness and applicability, record that project's transfer separately |
| Project forecast cannot be generalized | Formula/scenario assumptions may be topic research, actual project forecast stays local |
| Supplied old report names a project | Preserve original and attribution, no automatic rewriting or renaming |
| Named competitor or exact quote in evidence | Retain identity when necessary for provenance |
| No project request | Deliver useful independent research without inventing an application layer |

These are reviewable contract examples, not fresh model behavior evidence.
